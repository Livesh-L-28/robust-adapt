    2. Pillar 1: ALA (Adaptive Learning Algorithms)¶

    2.1 Hoeffding Bound Split Invariant¶

    In VectorizedHoeffdingTree, split decisions at leaf node \(u\) are governed by the Hoeffding inequality. Let \(n_u\) be the cumulative sample count at node \(u\), and let \(C\) be the number of discrete classes.

    The Gini impurity is defined as: $\(G(u) = 1 - \sum_{c=1}^C p_{u, c}^2\)$

    Because the Gini index is bounded in \([0, 1 - 1/C]\), the range of the random variable \(R_G\) is: $\(R_G = 1 - \frac{1}{C}\)$

    The Hoeffding bound for split confidence \(1 - \delta\) after \(n_u\) independent observations is: $\(\epsilon_H = \sqrt{\frac{R_G^2 \ln(1/\delta)}{2 n_u}}\)$

    Let \(\Delta G(A_1)\) be the Gini gain of the best candidate attribute, and let \(\Delta G(A_2)\) be the gain of the second-best attribute. A split is executed if and only if: $\(\Delta G(A_1) - \Delta G(A_2) > \epsilon_H \quad \lor \quad \epsilon_H < \tau_{\text{tie}}\)$

    Code Verification (adaptive_ml/ala/tree.py#L274-L280)¶

    R_G = 1.0 - (1.0 / self.n_classes)
epsilon_H = math.sqrt((R_G ** 2 * math.log(1.0 / self.delta)) / (2.0 * n_u))
delta_G = best_gain_1 - max(0.0, best_gain_2)

if (delta_G > epsilon_H) or (epsilon_H < self.tau_tie):
    threshold = float(self.bin_edges[best_feat_1, best_bin_1])
    self._split_leaf(leaf, best_feat_1, threshold)
    - Asymptotic Check: As \(n_u \to \infty\), \(\epsilon_H \to 0\). The condition \(\epsilon_H < \tau_{\text{tie}}\) correctly breaks near-ties between identical candidate features, preventing infinite stagnation. - Dtype & Invariant: Verified correct.

    2.2 Reliability-Weighted ADWIN Harmonic Sample Size & Cut Bound¶

    In ReliabilityWeightedADWIN, an adaptive sliding window \(W\) is evaluated across all binary sub-window partitions \(W = W_0 \cdot W_1\). Let \(w_0 = \sum_{i \in W_0} r_i\) and \(w_1 = \sum_{i \in W_1} r_i\) be the cumulative reliability sums of each partition, and let \(\mu_0, \mu_1\) be their reliability-weighted means.

    The effective harmonic sample size \(m\) is derived as: $\(m = \frac{1}{\frac{1}{w_0} + \frac{1}{w_1}} = \frac{w_0 w_1}{w_0 + w_1}\)$

    The statistical Hoeffding cut threshold with total window instance count \(n\) is: $\(\epsilon_{\text{cut}} = \sqrt{\frac{1}{2m} \ln\left(\frac{4n}{\delta}\right)}\)$

    Drift is declared and the window tail \(W_0\) is dropped when: $\(|\mu_0 - \mu_1| \ge \epsilon_{\text{cut}} \iff \delta_{\text{drift}} = \frac{|\mu_0 - \mu_1|}{\epsilon_{\text{cut}} + \epsilon_{\text{div}}} \ge 1.0\)$

    Code Verification (adaptive_ml/ala/adwin.py#L149-L164)¶

    inv_m = (1.0 / w_0) + (1.0 / w_1)
m_eff = 1.0 / inv_m

abs_diff = abs(mu_0 - mu_1)
eps_cut = math.sqrt((1.0 / (2.0 * m_eff)) * math.log(4.0 * self.window_total_count / self.delta))
delta_drift = abs_diff / (eps_cut + EPS_DIV)

if abs_diff >= eps_cut:
    drift_detected = True
    - Harmonic Bound Properties: If corrupted samples have near-zero reliability (\(r_i \approx 0\)), \(w_1\) does not grow, \(m_{\text{eff}} \to 0\), causing \(\epsilon_{\text{cut}} \to \infty\). This proves why noise bursts cannot artificially force an ADWIN cut. - Dtype & Invariant: Verified correct.

    3. Pillar 2: RLA (Robust Learning Algorithms)¶

    3.1 Theorem 2: Minority Class Preservation Proof & Verification¶

    Theorem 2 (Minority Preservation Guarantee):
    Let \(\mathcal{D}\) be a streaming data distribution with class imbalance ratio \(\frac{N_0}{N_1} \gg 1\), corrupted by symmetric label noise \(\eta \in [0, 0.5)\). Let sample reliability \(r(x, y)\) be defined by coupling local sample density \(\rho(x)\) with logit margin \(\Delta(x, y)\): $\(r(x, y) = \sigma\left(\kappa \cdot (\rho(x) \cdot \Delta(x, y) - \tau)\right)\)$ where: $\(\rho(x) = \frac{1}{\frac{1}{k}\sum_{j \in \mathcal{N}_k(x)} \|x - x_j\|_2 + \epsilon_{\text{div}}}, \quad \Delta(x, y) = z_y - \max_{c \neq y} z_c\)$

    Mathematical Proof:¶

    1. Unweighted Margin Failure:
      In standard unweighted loss filtering (e.g., Cleanlab or standard margin thresholding), samples in sparse regions of the feature space naturally possess lower classifier confidence \(\Delta(x, y) \approx 0\) due to lack of local support. When unweighted thresholding \(\Delta(x, y) > \tau\) is applied under class imbalance: $\(\mathbb{P}(\text{Retain} \mid x \in C_{\text{minority}}) \ll \mathbb{P}(\text{Retain} \mid x \in C_{\text{majority}})\)$ As \(\frac{N_0}{N_1} \to \infty\), all minority samples are discarded as suspected noise, resulting in \(0.0\%\) minority recall.

    2. Density-Modulated Preservation:
      True minority instances belong to compact sub-manifolds where intra-minority distances are small, yielding high local density \(\rho(x) \approx \rho_{\text{minority}} > 0\).
      Conversely, randomly corrupted labels (e.g., majority instances erroneously assigned minority labels, or vice versa) represent isolated, out-of-distribution points relative to the assigned label manifold, having very low density \(\rho(x_{\text{corrupt}}) \approx 0\) and negative margin \(\Delta < 0\).
      Therefore: $\(\rho(x_{\text{minority}}) \cdot \Delta(x_{\text{minority}}) \gg \tau \implies r(x_{\text{minority}}) \to 1.0\)$ $\(\rho(x_{\text{noise}}) \cdot \Delta(x_{\text{noise}}) < \tau \implies r(x_{\text{noise}}) \to 0.0\)$

    Empirical Validation (test_rla.py#L32-L47)¶

    Tested under 100:1 synthetic imbalance with \(20\%\) noise: - Minority class sample weights: mean \(0.842 > 0.50\) - Corrupted label sample weights: mean \(0.124 < 0.20\) - Resulting minority recall: \(60.0\%\) for AdaptiveML vs \(0.0\%\) for unweighted Cross-Entropy. Theorem 2 holds.

    3.2 Symmetric Cross-Entropy Loss Analytical Gradients¶

    SymmetricCrossEntropyLoss implements the symmetric objective: $\(\mathcal{L}_{\text{SCE}}(p, q) = \alpha \mathcal{L}_{\text{CE}}(p, q) + \beta \mathcal{L}_{\text{RCE}}(p, q)\)$ $\(\mathcal{L}_{\text{SCE}} = -\alpha \sum_{c=1}^C q_c \ln(p_c) - \beta \sum_{c=1}^C p_c \ln(q_c)\)$ where \(q\) is the one-hot ground-truth distribution and \(p = \text{softmax}(z)\) are predicted probabilities.

    Analytical Gradient Derivation:¶

    \[\frac{\partial \mathcal{L}_{\text{CE}}}{\partial z_c} = p_c - q_c\]

    For Reverse Cross-Entropy (\(\mathcal{L}_{\text{RCE}} = -\sum_k p_k \ln q_k\)): $\(\frac{\partial \mathcal{L}_{\text{RCE}}}{\partial z_c} = \sum_{k=1}^C \frac{\partial \mathcal{L}_{\text{RCE}}}{\partial p_k} \frac{\partial p_k}{\partial z_c} = \sum_{k=1}^C (-\ln q_k) \cdot (p_k \delta_{kc} - p_k p_c)\)$ $\(= -p_c \ln q_c + p_c \sum_{k=1}^C p_k \ln q_k\)$

    Combining terms: $\(\frac{\partial \mathcal{L}_{\text{SCE}}}{\partial z_c} = \alpha (p_c - q_c) + \beta p_c \left(\sum_{k=1}^C p_k \ln(q_k + \epsilon) - \ln(q_c + \epsilon)\right)\)$

    Numerical Verification (test_rla.py#L50-L75)¶

    Finite difference gradient checking verified analytical gradients to within machine tolerance: $\(\max \left|\nabla_{\text{analytical}} - \nabla_{\text{finite\_diff}}\right| < 1.0 \times 10^{-5}\)$

    4. Pillar 3: RAO (Resource-Aware Optimization)¶

    4.1 8-Bit Block Quantization Bound Invariant¶

    In BlockQuantizer, continuous parameter tensors are partitioned into contiguous blocks of size \(B_q\) (\(B_q = 64\) or \(256\)). For block \(b\):

    \[\text{scale}_b = \frac{\max_{i \in b} |w_i|}{127.0}$$ $$q_i = \text{clip}\left(\left\lfloor \frac{w_i}{\text{scale}_b} + 0.5 \right\rfloor, -127, 127\right) \in \text{int8}$$ $$\hat{w}_i = q_i \cdot \text{scale}_b\]

    Theoretical Quantization Invariant:¶

    Because round-to-nearest rounding is applied: $\(\left| \frac{w_i}{\text{scale}_b} - q_i \right| \le \frac{1}{2}\)$ Multiplying by \(\text{scale}_b\): $\(|w_i - \hat{w}_i| \le \frac{\text{scale}_b}{2} + \epsilon_{\text{quant}}\)$

    Numerical Test Verification (test_rao.py#L22-L43)¶

    Across \(10,000\) random normal vectors with arbitrary variance: $\(\forall b, \quad \max_{i \in b} |w_i - \hat{w}_i| \le \frac{\text{scale}_b}{2.0} + 1.0 \times 10^{-6}\)$ Strictly verified across all seeds.

    4.2 Exact Memory Footprint Equation¶

    Standard FP32 AdamW tracks two FP32 states per parameter: first moment \(m\) (4 bytes) and second moment \(v\) (4 bytes), requiring \(8.0\text{ Bytes/parameter}\).

    In LowMemoryAdamW: - \(m\): Quantized signed int8 \(\implies 1.0\text{ Byte/parameter}\) - \(v\): Quantized unsigned uint8 \(\implies 1.0\text{ Byte/parameter}\) - Scales for \(m\): FP32 scale per block \(\implies \frac{4}{B_q}\text{ Bytes/parameter}\) - Scales for \(v\): FP32 scale per block \(\implies \frac{4}{B_q}\text{ Bytes/parameter}\)

    \[\text{Bytes per parameter} = 1 + 1 + \frac{4 + 4}{B_q} = 2 + \frac{8}{B_q}\]

    For default block size \(B_q = 64\): $\(\text{Bytes per parameter} = 2 + \frac{8}{64} = 2.125\text{ Bytes/parameter} \quad (\mathbf{73.4375\%\text{ RAM reduction}})\)$

    For large block size \(B_q = 256\): $\(\text{Bytes per parameter} = 2 + \frac{8}{256} = 2.03125\text{ Bytes/parameter} \quad (\mathbf{74.609\%\text{ RAM reduction}})\)$

    Empirical inspection via optimizer.get_state_memory_bytes() matches this theoretical value with zero byte variance.

    5. Pillar 4: ULC (Unified Learning Controller)¶

    5.1 5-State Finite Automaton Transition Kernel¶

    The arbitration automaton in ArbitrationAutomaton maps current operational state \(S \in \mathcal{S}\) and synthesized evidence vector \(e_\tau = (\delta, \bar{r}, H_p, \nabla \mathcal{L})\) to next state \(S' \in \mathcal{S}\):

    \[\mathcal{S} = \{\text{STABLE}, \text{WARNING}, \text{CONFIRMED\_DRIFT}, \text{NOISE\_BURST}, \text{RECOVERY}\}\]
    stateDiagram-v2
    [*] --> STABLE
    STABLE --> WARNING: delta >= 0.5
    STABLE --> CONFIRMED_DRIFT: delta >= 1.0 and rel >= tau_R
    STABLE --> NOISE_BURST: delta >= 1.0 and rel < tau_R

    WARNING --> STABLE: delta < (0.5 - Delta_hyst)
    WARNING --> CONFIRMED_DRIFT: delta >= 1.0 and rel >= tau_R
    WARNING --> NOISE_BURST: delta >= 1.0 and rel < tau_R

    CONFIRMED_DRIFT --> RECOVERY: immediate (set dwell)
    RECOVERY --> STABLE: dwell == 0 and delta < 0.5
    RECOVERY --> RECOVERY: dwell > 0 or delta >= 0.5

    NOISE_BURST --> STABLE: rel >= tau_R and delta < 0.5
    NOISE_BURST --> NOISE_BURST: rel < tau_R or delta >= 0.5

    5.2 Hysteresis Deadband Invariant¶

    To prevent high-frequency limit-cycle oscillation ("chattering") between STABLE and WARNING under noisy signal fluctuations near threshold \(0.5\), a hysteresis deadband \(\Delta_{\text{hyst}} = 0.15\) is enforced:

    • Transition \(\text{STABLE} \to \text{WARNING}\): requires \(\delta \ge 0.50\)
    • Transition \(\text{WARNING} \to \text{STABLE}\): requires \(\delta < (0.50 - \Delta_{\text{hyst}}) = 0.35\)

    Deadband Invariant Proof:¶

    When the stream divergence fluctuates in the open interval \(\delta \in [0.35, 0.50)\): - If the system is currently in STABLE, it remains in STABLE. - If the system is currently in WARNING, it remains in WARNING.

    This guarantees that at least \(\Delta_{\text{hyst}} = 0.15\) normalized divergence drop is required to de-escalate warnings, provably eliminating single-step state jitter. Verified in test_ulc.py#L48-L62.
