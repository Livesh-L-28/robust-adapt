    5. Existing Developer Experience Deficiencies¶

    1. Top-Level Package Namespace Empty: adaptive_ml/__init__.py only exposes ["ala", "rla", "rao", "ulc", "core"]. A developer importing import adaptive_ml as aml cannot access aml.AdaptiveClassifier, aml.LowMemoryAdamW, or aml.UnifiedLearningControllerV4_1 without traversing submodule paths.
    2. Inconsistent Configuration Interfaces: ALA uses direct class arguments (n_features, grace_period, tau_tie). RAO uses dataclasses (AdamWConfig). ULC-v4.1 uses ULCv41Config. A standardized configuration experience is needed.
    3. Documentation Dispersion: Existing documentation in docs/ is scattered across historical phase folders (docs/engineering/, docs/release/) and lacks an organized, modern developer-facing structure (docs/getting_started/, docs/tutorials/, docs/api/).
    4. Example Coverage Gaps: Existing examples in examples/ only cover basic standalone use cases and lack deterministic outputs, problem descriptions, and several required scenarios (e.g., gradual drift, delayed labels, partial-pillar ULC).
