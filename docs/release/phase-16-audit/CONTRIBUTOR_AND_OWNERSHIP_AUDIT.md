## 1. Contributor Governance & DCO 1.1 Enforcement

In accordance with Phase 0 Project Charter (`DOC-FDN-002`) and Licensing Policy (`DOC-FDN-006`):

1. **Developer Certificate of Origin (DCO 1.1)**:
   All Git commits across the development lifecycle contain mandatory `Signed-off-by` trailers affirming contributor rights to submit code under the Apache-2.0 license.
2. **Copyright Ownership**:
   Copyright is held collectively by the AdaptiveML Core Development Team and individual contributors.
3. **No Contributor License Agreement (CLA) Overhead**:
   DCO 1.1 avoids corporate CLA friction while ensuring unbroken legal provenance.
